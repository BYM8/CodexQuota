## 项目介绍

Codex 余量是一个用于查看本机 Codex 使用限额的轻量工具。

## 我应该下载哪个文件

普通用户不要下载 GitHub 绿色 `Code` 按钮里的源码包，请到 Releases 页面下载安装包：

```text
https://github.com/BYM8/CodexQuota/releases
```

在 Releases 页面按系统选择：

- 苹果电脑下载 `CodexQuota-macOS.zip`
- Windows 电脑下载 `CodexQuota-Windows.zip`
- 开发者或想改代码，才下载 `Source code`

## 新手安装教程

### macOS 用户

1. 打开 Releases 页面
2. 下载 `CodexQuota-macOS.zip`
3. 解压压缩包
4. 双击 `CodexQuota.app`
5. 顶部菜单栏出现百分比后，说明已经启动
6. 点击菜单栏百分比，可以打开详情面板

如果 macOS 提示无法打开：

1. 打开「系统设置」
2. 进入「隐私与安全性」
3. 找到被拦截的 `CodexQuota.app`
4. 点击「仍要打开」

### Windows 用户

1. 打开 Releases 页面
2. 下载 `CodexQuota-Windows.zip`
3. 解压压缩包，不要直接在压缩包里运行
4. 打开解压后的 `CodexQuotaWin` 文件夹
5. 双击 `Start-CodexQuotaWin.bat`
6. 右下角系统托盘出现 Codex 余量图标后，说明已经启动

Windows 托盘图标使用方法：

- 右键图标查看状态
- 双击图标弹出当前余量
- 右键选择「立即刷新」重新读取
- 右键选择「打开 Codex 日志目录」查看本机日志
- 右键选择「退出」关闭工具

Windows 新版包说明：

- 不下载任何文件
- 不隐藏运行
- 不绕过 PowerShell 执行策略
- 不自动写入开机启动

如果安全软件提示，请确认下载来源是本项目 Release，并确认文件名是 `CodexQuota-Windows.zip`。

## macOS 版本

macOS 版本是原生菜单栏应用。启动后会在顶部菜单栏显示当前剩余百分比，点击菜单栏图标可以打开详情面板。

### 功能

- 自动读取本机 Codex 会话日志
- 显示剩余额度、已用额度、周期、重置时间和套餐类型
- 菜单栏常驻显示
- 支持登录后自动启动
- 带动态菜单栏图标和进度条光效

### 环境要求

- macOS 12 或更高版本
- Apple Command Line Tools，包含 `swiftc`

### 安装

```bash
./install.sh
```

安装后应用位置：

```text
/Applications/CodexQuota.app
```

### 卸载

```bash
./uninstall.sh
```

## Windows 版本

Windows 版本是 PowerShell 托盘版，不依赖 Node、Python 或 Electron。安装后会在系统托盘区域显示 Codex 余量，右键托盘图标可以刷新、打开日志目录或退出。

### 功能

- 自动读取 `%USERPROFILE%\.codex\sessions` 下的 Codex 会话日志
- 每 30 秒刷新一次
- 系统托盘显示状态
- 不下载任何文件
- 不隐藏运行
- 不绕过 PowerShell 执行策略

### 环境要求

- Windows 10 或更高版本
- Windows PowerShell 5.1 或 PowerShell 7+

### 安装

解压 `CodexQuota-Windows.zip` 后，运行：

```text
Start-CodexQuotaWin.bat
```

如果系统提示是否允许运行本地脚本，请确认文件来自本项目 Release 后再允许。

### 卸载

右键托盘图标选择「退出」，然后删除解压出来的文件夹即可。

如果你之前安装过旧版 Windows 包，请额外删除旧版自动启动文件：

```text
%LOCALAPPDATA%\CodexQuotaWin
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\CodexQuotaWin.lnk
```

## 数据来源说明

本工具读取的是本机 Codex 会话日志中的 `rate_limits.primary.used_percent` 等字段，并不是官方公开 API。

如果 Codex 后续调整日志格式，可能需要更新解析逻辑。
